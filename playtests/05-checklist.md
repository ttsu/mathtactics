# Playtest 5 — Checklist

**Question:** does Easy feel like relief on waves 8–9, and does Hard feel like more to think
about without becoming mean?

**Setup:** iPad in landscape, the PR preview (or production) already on the Home Screen. Open
the app → **New Game**. A full-screen picker with three star buttons should appear (1 / 2 / 3
stars). Play **Easy** one session and **Hard** another (or the reverse if he asks for harder
first). Do **not** tap ▶ Keep Going from an earlier Normal run — that resume stays whatever
difficulty that save already is.

Playtest 4 notes (`playtests/04.md`) were not written yet when this checklist was authored, so
this session does not re-ask trait-readability, Boss-as-finale, or Settings/hints questions
from Playtest 4. Those still belong to H4 on **Normal**.

**Your role:** hand him the iPad and say as little as possible. Don't explain what the stars
mean. If he asks, answer with a question ("which one looks like the one you want?"). Only
step in if he is stuck *and* unhappy for more than a minute or so — and note that you did.

## What is different (for you, not him)

Same 10-wave concept ladder, same shop, same starting kit, same 1000 HP 2×2 Boss. Only the
stretch changes:

| | Easy (1 star) | Hard (3 stars) |
|---|---|---|
| Waves 1–7 | Same robots; smaller HP | Same robots and HP as Normal |
| Waves 8–9 | One fewer robot per pack; smaller HP | One more robot per pack; every robot has a trait (no `basic`) |
| Wave 10 | Boss still 1000 | Boss still 1000 |
| Never placing tiles | Still loses | Still loses |

## What to watch for

Tick or jot a word next to each as it happens.

**Picker**
- [ ] Does he **pick a star on his own**, without being told what they mean?
- [ ] Does he notice **Normal is the middle one** (two stars)?
- [ ] Cover the labels: do the **star counts** still distinguish the three?
- [ ] Does he tap ← **Back** (top left) from the picker by accident? Does he understand nothing started?

**Easy session**
- [ ] Waves 8–9: relief, boredom, or still a stretch?
- [ ] Does a leak feel like a **chip**, or still scary?
- [ ] After he wins (or you stop): does he want **Harder** next, or the same again?

**Hard session**
- [ ] Waves 8–9: more to think about, or mean? Too many robots at once?
- [ ] Does "every robot has a mark" land, or just look busy?
- [ ] Does he **reach the Boss**, or lose on 8–9?
- [ ] After: want Easy next, or another Hard?

**Keep Going / Settings (you can demo, not him)**
- [ ] Mid-run Home → ▶ Keep Going: **no picker**. The run stays the difficulty he started.
- [ ] Settings three-way: changing the stars there does **not** change the run already going.

**End-Turn-only lose (you demo, not him)**
- [ ] On Easy, never placing tiles still **loses**. Does that surprise him if he watches?

**Afterwards (ask him)**
- [ ] Which star-game was more fun?
- [ ] Which was too easy? Too hard?
- [ ] Want to pick the stars himself next time?
